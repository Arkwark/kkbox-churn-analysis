# Анализ оттока пользователей стримингового сервиса KKBox

## 📌 Краткое резюме (TL;DR)
Проект посвящен исследованию причин оттока пользователей на основе реальных данных (WSDM Cup 2018). В ходе работы выявлены ключевые драйверы оттока, подтвержденные статистическими тестами. Главный вывод: низкая активность в первые дни и молодой возраст — главные факторы риска. Подготовлены конкретные бизнес-рекомендации по удержанию (онбординг и молодежные тарифы).

## 📊 Данные
Использован открытый датасет [KKBox Churn Prediction Challenge](https://www.kaggle.com/c/kkbox-churn-prediction-challenge). 
* **Объем:** ~1 млн уникальных пользователей, 18.3 млн записей о прослушивании.
* **Период:** Январь 2015 — Март 2017.
* **Таблицы:** Демография, транзакции, логи прослушивания, целевая переменная.

## 🛠 Этапы работы
1. **Data Audit:** Первичный анализ структуры, поиск пропусков. Выявлен дисбаланс классов (доля оттока — 9%).
2. **Feature Engineering:** Агрегация данных на уровне пользователя (сумма платежей, общее время прослушивания, количество отмен и т.д.).
3. **Data Preparation:** Обработка пропусков (документирование допущений).
4. **EDA & Statistical Testing:** Визуализация распределений и проверка гипотез (Mann-Whitney U test, Chi-square test).

## 💡 Ключевые инсайты
1. **Активность — главный предиктор оттока.** Медианное время прослушивания у оставшихся пользователей на 30% выше, чем у ушедших (51 167 сек. против 38 419 сек., *p-value < 0.001*). Пользователи с нулевой активностью уходят почти гарантированно.
2. **Молодежь уходит чаще.** Уровень оттока среди пользователей младше 25 лет составляет **18.1%**, что в 2.5 раза выше, чем в группе 25–35 лет (7.2%). Разница статистически значима (*p-value < 0.001*).

## 💼 Бизнес-рекомендации
1. **Онбординг в первые дни:** Мотивировать пользователя слушать музыку в первые 3-7 дней (умные подборки, бесплатный премиум на неделю).
2. **Специальные предложения для молодежи:** Студенческие тарифы, геймификация, интеграция с соцсетями для обмена плейлистами.

## 📂 Структура репозитория
* `data/` — папки для сырых (`raw`) и обработанных (`processed`) данных (игнорируются Git).
* `notebooks/` — Jupyter-ноутбуки с этапами анализа (01_audit, 02_features, 03_eda).
* `reports/` — графики и визуализации.
* `requirements.txt` — зависимости проекта.

## 🚀 Как запустить
1. Клонируйте репозиторий.
2. Скачайте данные с Kaggle и положите в `data/raw/`.
3. Установите зависимости: `pip install -r requirements.txt`.
4. Запустите ноутбуки в папке `notebooks/` по порядку.
